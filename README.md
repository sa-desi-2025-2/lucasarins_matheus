## 💡 Sobre o Projeto

O Sistema de Análise de Custo-Benefício de Manutenção (ROI) é uma plataforma web desenvolvida para auxiliar empresas e indivíduos na tomada de decisão sobre seus ativos (máquinas, equipamentos, etc.). O objetivo central é determinar se o Retorno sobre Investimento (ROI) obtido pela extensão da vida útil de um ativo justifica os gastos acumulados com sua manutenção e reparos.


>A ferramenta fornece uma visão clara do Custo Total de Propriedade (TCO) ao longo do tempo, permitindo decisões objetivas sobre manter, substituir ou vender um equipamento.

## ⚠️ Pré-requisitos

1.  **Git:** Necessário para clonar o repositório do projeto.
    ```bash
    # Verifique a instalação
    git --version
    ```
2.  **Python:** O *backend* utiliza a linguagem Python (recomendado usar a versão 3.9+).
    ```bash
    # Verifique a instalação
    python --version
    ```
3.  **Gerenciador de Ambientes Virtuais (Virtualenv ou Venv):** Altamente recomendado para isolar as dependências do projeto.
4.  **MySQL / MariaDB:** Um servidor de banco de dados SQL é necessário.
    * Recomenda-se o uso de ferramentas como **Docker** para subir o banco de dados facilmente, ou instalá-lo diretamente (via XAMPP, WAMP, ou instalação nativa).
5.  **Pip (Gerenciador de Pacotes Python):** Geralmente vem instalado com o Python.
    ```bash
    # Verifique a instalação
    pip --version
    ```
6.  **Variáveis de Ambiente:** Você precisará configurar as variáveis de ambiente (como as credenciais do banco de dados e a `SECRET_KEY` do Django) em um arquivo `.env` ou similar.
